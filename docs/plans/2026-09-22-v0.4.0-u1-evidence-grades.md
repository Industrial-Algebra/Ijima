# Unit 1 — Evidence-grade memory model (direction D, first half)

**Depends on:** nothing (first rung of the v0.4.0 trust-machinery ladder).
**Followed by:** Unit 2 (supersede mechanism) — this unit's fields are its substrate.

## Purpose

Every `Memory` carries an evidence grade (`Observed` vs `Interpreted`) and
typed citations. Legacy rows (no field) deserialize as `Interpreted` —
ungraded claims are the weaker claim by construction. Saving an `Observed`
memory without at least one citation is rejected. Auto-capture (which
literally observed the session) stamps `Observed` with a session citation.

## Contracts

### `ijima-core/src/memory.rs` — add after the `Memory` struct

```rust
/// Evidence grade (direction D, v0.4.0): is this content a claim the
/// authoring process directly observed, or an interpretation it formed?
/// Composes with the provenance tiers — the grade crosses tier lines
/// (an explicit save can still be an interpretation), so it is its own
/// axis. Defaults to `Interpreted`: ungraded and legacy rows are the
/// weaker claim, never masquerading as observed fact.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
#[cfg_attr(feature = "serde", derive(serde::Serialize, serde::Deserialize))]
pub enum EvidenceGrade {
    /// Directly observed behavior/event: the authoring process witnessed
    /// the thing itself (a session transcript event, a command output, a
    /// git artifact). Requires at least one [`Citation`].
    Observed,
    /// An interpretation, inference, claim, or summary formed about
    /// artifacts or events. No citation requirement — attribution is the
    /// grade itself.
    Interpreted,
}

impl Default for EvidenceGrade {
    fn default() -> Self {
        EvidenceGrade::Interpreted
    }
}

/// A typed pointer to the artifact that grounds an [`EvidenceGrade::Observed`]
/// memory. "No citation, no candidate" — observed claims cite or they do
/// not ship.
#[derive(Debug, Clone, PartialEq, Eq)]
#[cfg_attr(feature = "serde", derive(serde::Serialize, serde::Deserialize))]
pub struct Citation {
    /// What kind of artifact the locator points at.
    pub kind: CitationKind,
    /// Opaque locator: commit sha, report path, session id, file path, URL.
    pub locator: String,
}

/// The artifact kinds Ijima knows how to cite (v0.4.0 set).
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
#[cfg_attr(feature = "serde", derive(serde::Serialize, serde::Deserialize))]
pub enum CitationKind {
    /// A git commit sha.
    Commit,
    /// A path (or id) into the report corpus.
    Report,
    /// An Ijima session id.
    Session,
    /// A file path.
    File,
    /// A URL.
    Url,
}
```

### `Memory` struct — add two fields after `importance`, before `created_at`

```rust
    /// Evidence grade (direction D). Defaults to `Interpreted` — legacy
    /// rows and ungraded saves are interpretations, never observed fact.
    #[cfg_attr(feature = "serde", serde(default))]
    pub evidence: EvidenceGrade,
    /// Citations grounding an `Observed` grade. Validated non-empty at
    /// save time (see [`Memory::validate_evidence`]); meaningless (and
    /// typically empty) for `Interpreted`.
    #[cfg_attr(feature = "serde", serde(default))]
    pub citations: Vec<Citation>,
```

### `memory.rs` — add validation + `Default` impls

```rust
impl Memory {
    /// Direction D invariant: an `Observed` memory must carry at least one
    /// citation. Returns a human-readable error string (mapped to 400 at
    /// the API layer) when violated.
    pub fn validate_evidence(&self) -> Result<(), String> {
        if self.evidence == EvidenceGrade::Observed && self.citations.is_empty() {
            Err(format!(
                "memory {} claims EvidenceGrade::Observed but cites nothing — \
                 observed claims require >= 1 citation",
                self.id.0
            ))
        } else {
            Ok(())
        }
    }
}
```

`Memory` already derives or impls `Default` if present — if it does, add
`evidence: EvidenceGrade::default(), citations: Vec::new()` to that impl.
If `Memory` has NO `Default`, do not add one.

### `ijima-server/src/extractor.rs` — auto-capture stamping

At every site that constructs an auto-capture `Memory`: set
`evidence: EvidenceGrade::Observed` and, when a session id is available,
`citations: vec![Citation { kind: CitationKind::Session, locator: <session id string> }]`;
with no session id available, fall back to `EvidenceGrade::Interpreted`
with empty citations. Auto-capture witnessed the session — it cites it.

### All other construction sites

Every remaining `Memory {` construction site gains
`evidence: EvidenceGrade::Interpreted, citations: Vec::new()` (miners
extract interpretations; migrations reconstruct history as interpreted).
Compile errors are the checklist.

## Tests (enumerate exactly; no others)

`ijima-core/src/memory.rs` (in the existing `mod tests`):

1. `legacy_json_deserializes_as_interpreted` — deserialize
   `{"id":"mem_x","content":"c","project":"p","topic":"t","source":"Mined","harness":"Pi","importance":0.5,"created_at":"1"}`
   (no evidence/citations keys) → `evidence == EvidenceGrade::Interpreted`,
   `citations.is_empty()`.
2. `validate_evidence_rejects_observed_without_citations` — Observed, empty
   citations → `Err` containing the memory id.
3. `validate_evidence_accepts_observed_with_citation` — Observed +
   `Citation { kind: CitationKind::Commit, locator: "abc123".into() }` → `Ok(())`.
4. `validate_evidence_accepts_interpreted_without_citations` → `Ok(())`.
5. `evidence_grade_serializes_pascalcase` — serde_json round-trip of
   `EvidenceGrade::Observed` produces the string `"Observed"`.

`ijima-server/src/api.rs` (existing test module, existing patterns):

6. `store_memory_rejects_observed_without_citations` — POST /memories with
   a full valid Memory (PascalCase enums as the API requires) whose
   `evidence` is `"Observed"` and `citations` is `[]` → 400 with body
   containing "cites nothing". Same body with one citation → 200.

`ijima-server/src/extractor.rs` (or its test module):

7. `autocapture_stamps_observed_with_session_citation` — run the
   auto-capture extraction on a fixture transcript with a session id;
   assert every produced memory has `evidence == Observed` and exactly one
   citation of kind `Session` whose locator is that session id.
