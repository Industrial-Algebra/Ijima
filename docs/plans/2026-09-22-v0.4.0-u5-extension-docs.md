## Contracts

### `index.ts` — `memory_save` parameters (extend `Type.Object`)

```ts
      evidence: Type.Optional(
        Type.Union(
          [Type.Literal("Observed"), Type.Literal("Interpreted")],
          {
            description:
              "Evidence grade. Observed = you directly witnessed this " +
              "(command output, file content, an event in this session) " +
              "— requires >= 1 citation and the server rejects otherwise. " +
              "Interpreted (default) = inference, judgment, or summary " +
              "about artifacts.",
          },
        ),
      ),
      citations: Type.Optional(
        Type.Array(
          Type.Object({
            kind: Type.Union(
              [
                Type.Literal("Commit"),
                Type.Literal("Report"),
                Type.Literal("Session"),
                Type.Literal("File"),
                Type.Literal("Url"),
              ],
              { description: "Artifact kind the locator points at" },
            ),
            locator: Type.String({
              description:
                "Opaque locator: commit sha, report path, session id, " +
                "file path, or URL",
            }),
          }),
          {
            description:
              "Citations grounding an Observed grade " +
              "(no citation, no observed claim)",
          },
        ),
      ),
      supersedes: Type.Optional(
        Type.String({
          description:
            "Id of the memory this one corrects. Superseded memories " +
            "drop out of wake-up/search/browse regardless of importance " +
            "— the correction displaces its target. Chain by superseding " +
            "the successor, not the already-superseded original.",
        }),
      ),
```

`execute` forwards them: extend `build_save_request` with a sixth
optional argument `extras?: { evidence?: string; citations?: unknown[]; supersedes?: string }`
setting body fields ONLY when present (absent params must produce a body
with NO `evidence`/`citations`/`supersedes` keys — the server defaults
apply). The tool description line gains:
`" Claims you directly observed should pass evidence: \"Observed\" with citations; corrections pass supersedes."`

Auto-capture path: NO change — the server stamps auto-capture rows
(server-side since U1).

### `SKILL.md` — add a section "Evidence grades and corrections (0.4)"

Content (adapt to the file's existing voice):
- Every save carries a grade; default Interpreted. Use `Observed` +
  citations when the session directly witnessed the fact (command
  outputs, file reads, events) — the server rejects Observed without
  citations.
- Corrections: pass `supersedes: <id>` — the target drops from
  wake-up/search/browse; corrections displace regardless of the target's
  importance. Do not re-save a correction as a fresh memory and hope
  ranking sorts it out.
- Doctrine (ns walls seeded from corpus): versioned server-side; ingest
  responses carry stance warnings; rollback is admin-only.

### `config.test.mjs` (or `save.test.mjs`) — offline tests

1. `save body omits evidence keys when params absent` —
   `build_save_request(...)` with no extras → JSON.parse(body) has no
   `evidence`, no `citations`, no `supersedes` keys.
2. `save body forwards evidence extras verbatim` — extras with
   `evidence: "Observed"`, one citation `{kind: "Commit", locator:
   "abc"}`, `supersedes: "mem_old"` → parsed body carries all three
   exactly.
3. `save body forwards interpreted without citations` —
   `evidence: "Interpreted"` alone → key present, no `citations` key.

### `e2e.mjs` — extend the live sequence (follows existing patterns)

4. Save A (`evidence: "Observed"`, citation `{kind: "File", locator:
   "e2e"}`) → 200; save B with `supersedes: A.id` → 200; recall A shows
   `superseded_by == B.id`; wake-up omits A.
5. Save with `evidence: "Observed"`, no citations → non-2xx (400).
